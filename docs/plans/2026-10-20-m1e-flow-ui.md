# M1-E 流量统计与 Web UI 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 `internal/flow`（字节计数、1s 速率、60 采样点、1000 条日志环形缓冲、文件日志）与 `internal/ui`（内嵌页面、状态/域名/日志/证书 API、令牌鉴权、`/flowStatistics` 兼容端点），并接入 `run`。

**Architecture:** `flow.Tracker` 用原子计数 + ticker 采样；`flow.Ring` 保存最近 1000 条请求日志并向 SSE 订阅者广播；`flow.Logger` 同时写 ring、tracker 与 `log.file`；MITM 反向代理与隧道把请求日志交给 `flow.Logger`；`ui.Server` 独立监听 `ui_port`，页面注入随机令牌，变更接口校验 `X-FastGithub-Token`。

**Tech Stack:** Go 1.22，仅标准库（`embed`/`encoding/json`/`crypto/rand`/`crypto/sha256`/`sync/atomic`/`net/http`），无第三方模块；`CGO_ENABLED=0`。

**Spec:** `docs/specs/2026-10-20-fastgithub-go-design.md` §7.6（flow）、§7.7（ui）、§9.2（集成测试）。

## Global Constraints

- `/flowStatistics` 字段严格为 `TotalRead/TotalWrite/ReadRate/WriteRate`（PascalCase，整数）。
- 令牌：16 字节随机 hex，写入配置目录 `ui.token`（0600），页面服务端注入；变更接口用 `X-FastGithub-Token`，不匹配返回 401。
- 日志环形缓冲 1000 条；采样 60 个；速率单位 bytes/s。
- UI 独立端口 `server.ui_port`，监听 127.0.0.1；38457 只保留 PAC 与 `/flowStatistics`。
- 每个任务结束时 `go test ./...` 全绿、`go vet`/`gofmt` 无输出。

### Task 1: flow 包

**Files:** `internal/flow/flow.go`、`ring.go`、`logger.go` + 测试

**Interfaces:**
```go
type Entry struct { Time time.Time; Domain, Method string; Status int; Duration time.Duration; Read, Write int64 }
type Sample struct { Time time.Time; ReadRate, WriteRate int64 }
type Snapshot struct { TotalRead, TotalWrite, ReadRate, WriteRate int64; Samples []Sample }

type Tracker struct { /* atomic + mu */ }
func NewTracker(maxSamples int) *Tracker
func (t *Tracker) Add(read, write int64)
func (t *Tracker) Tick()
func (t *Tracker) Snapshot() Snapshot
func (t *Tracker) Run(ctx context.Context, interval time.Duration)

type Ring struct { /* mu, entries, max, subs */ }
func NewRing(max int) *Ring
func (r *Ring) Add(e Entry)
func (r *Ring) Recent() []Entry
func (r *Ring) Subscribe() (<-chan Entry, func())

type Logger struct { /* ring, tracker, file */ }
func NewLogger(ring *Ring, tracker *Tracker, filePath string) (*Logger, error)
func (l *Logger) Log(e Entry)
func (l *Logger) Close() error
```
- `Tick` 计算自上次的增量，追加样本并保留最后 `maxSamples` 个；`Snapshot` 返回累计值与最后一个样本的速率。
- Ring 满时覆盖最旧；订阅通道带缓冲，满时丢弃；`Subscribe` 返回取消函数。
- Logger 写文件格式：`2006-01-02T15:04:05Z07:00 domain method status duration read write`；`filePath` 为空时只写 ring/tracker。
- 测试：累计与速率、样本上限、ring 覆盖/订阅、logger 文件内容。

type DomainStat struct { Pattern string; Hits int64 }

### Task 3: MITM 请求日志

**Files:** `internal/mitm/reverse.go`、`tunnel.go`、`proxy.go`、`proxy_test.go`

**Interfaces:**
```go
type Logger interface { Log(flow.Entry) }
func (p *ReverseProxy) SetLogger(l Logger)
func (s *Server) SetLogger(l Logger)
func (s *Server) SetStats(h http.Handler)
```
- 反向代理：`countingReader` 包 `r.Body`、`countingWriter` 包 `ResponseWriter`；记录 domain/method/status/duration/read/write；短路响应与上游错误也记录。
- 隧道：`countingConn` 包客户端与上游；`Tunnel` 返回后记录 `CONNECT` 日志（status 200，读写总量）。
- `Server.ServeHTTP` 在非绝对 URI 且路径为 `/flowStatistics` 时交给 `SetStats` 的 handler（未设置则 404）。
- 测试：用假 logger 断言反向代理日志字段；隧道日志读写非零；`/flowStatistics` 命中自定义 handler。

### Task 4: UI 服务

**Files:** `internal/ui/server.go`、`token.go`、`assets/index.html`、`app.js`、`style.css` + 测试

**Interfaces:**
```go
type Options struct {
    Config *config.Config
    Store *config.Store
    Tracker *flow.Tracker
    Ring *flow.Ring
    CA *certs.Authority
    Token string
    InstallCert func(string) error
}
func New(opts Options) *Server
func (s *Server) Handler() http.Handler
func LoadOrCreateToken(path string) (string, error)
func FlowStatistics(t *flow.Tracker) http.Handler
```
- 路由：`/`、`/app.js`、`/style.css`、`/api/status`、`/api/domains`、`/api/logs`（SSE）、`/api/cert`、`/api/cert/install`、`/api/intercept`、`/flowStatistics`。
- 页面用 `embed` 内嵌，`{{TOKEN}}` 替换为令牌；SSE 先发 backlog 再推实时日志。
- `/api/status`：`version/proxyPort/uiPort/intercept/caFingerprint/dns{doh,fallback}`。
- `/api/cert`：PEM 下载；`/api/cert/install` 与 `/api/intercept` 需要令牌；后者返回 501（M2）。
- 测试：首页 200 且含令牌；无令牌 POST 401；带令牌调用注入的 install；`/api/domains`、`/api/status`、`/flowStatistics` 字段；SSE 收到一条日志。
