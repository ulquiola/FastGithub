# Windows 托盘常驻实现计划

> 目标：双击 `fastgithub.exe` 即启动代理并在通知区域常驻，右键菜单完成常用操作，不再需要命令行。

## 1. 交付物

| 文件 | 职责 |
|---|---|
| `internal/tray/tray.go` | 跨平台类型：`Options`、`Actions`、状态文本、菜单项定义 |
| `internal/tray/tray_windows.go` | Windows 实现：消息窗口、`Shell_NotifyIconW`、弹出菜单、图标、剪贴板、ShellExecute |
| `internal/tray/tray_other.go` | 非 Windows stub：`Run` 返回 `ErrUnsupported` |
| `internal/tray/autostart_windows.go` | 开机启动：读写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |
| `internal/tray/autostart_other.go` | 非 Windows stub |
| `internal/tray/icon_windows.go` | 从 `.ico` 字节创建 `HICON`（`CreateIconFromResourceEx`） |
| `internal/tray/assets/app.ico` | 图标（复制自原版，MIT） |
| `internal/tray/*_test.go` | 纯逻辑单测（见 §5） |
| `cmd/fastgithub/main.go` | 无参数 → 托盘；新增 `tray` 子命令 |
| `README.md` | 补充双击使用说明 |

## 2. 公共 API

```go
// tray.go
type Actions struct {
    OpenUI      func()          // 打开 http://127.0.0.1:<uiPort>/
    CopyProxy   func() error    // 复制 127.0.0.1:<proxyPort>
    InstallCert func() error    // 以管理员身份运行 install-cert
    Quit        func()          // 请求退出（关闭代理）
}

type Options struct {
    Version          string
    ProxyAddr        string
    UIAddr           string
    InterceptEnabled bool
    Admin            bool
    Actions          Actions
}

func StatusText(o Options) string   // 托盘提示
func MenuItems(o Options) []Item    // 菜单项定义（跨平台可测）
func Run(ctx context.Context, o Options) error
func AutostartEnabled() (bool, error)
func SetAutostart(enabled bool, configPath string) error  // configPath 必须是绝对路径
```

`Item{ID int, Label string, Enabled bool, Checked bool, Separator bool}`；ID 常量：
`IDOpenUI=1, IDCopyProxy=2, IDInstallCert=3, IDInterceptState=4, IDAutostart=5, IDQuit=6`。

## 3. Windows 实现要点

- `runtime.LockOSThread()`；`RegisterClassExW` + `CreateWindowExW` 建隐藏窗口（`HWND_MESSAGE` 或普通隐藏窗口），`syscall.NewCallback` 注册 `WndProc`。
- 自定义消息 `WM_APP+1` 接收托盘事件：`WM_RBUTTONUP` → `TrackPopupMenu`；`WM_LBUTTONDBLCLK` → 打开 UI。
- `Shell_NotifyIconW`：`NIM_ADD` / `NIM_SETVERSION` / `NIM_DELETE`；`NOTIFYICONDATAW` 结构体大小按 `unsafe.Sizeof` 传给 `cbSize`，字段 `hWnd/uID/uFlags/uCallbackMessage/szTip/szInfoFlags/hIcon`。
- 菜单：`CreatePopupMenu` + `AppendMenuW`（`MF_STRING`、`MF_GRAYED`、`MF_CHECKED`、`MF_SEPARATOR`）；用 `TrackPopupMenu(TPM_RETURNCMD|TPM_RIGHTBUTTON)` 直接拿命令 ID，避免 `WM_COMMAND`。
- 图标：`go:embed assets/app.ico`；解析 `ICONDIR`，优先取 32×32（或最近尺寸），`CreateIconFromResourceEx(data, size, true, 0x00030000, w, h, LR_DEFAULTCOLOR)`。
- 文本：所有 `*W` API 用 `syscall.UTF16PtrFromString`；`Dll` 用 `syscall.NewLazyDLL("user32.dll"/"shell32.dll"/"advapi32.dll"/"kernel32.dll")`。**不得引入 cgo**。
- 退出：菜单 Quit → 调 `Actions.Quit()`（由 CLI cancel 掉 app 的 context），随后 `NIM_DELETE`、`DestroyWindow`、`PostQuitMessage`，`Run` 返回。ctx 取消时同样走这段清理。
- 单实例：`CreateMutexW(nil,false,"Global\\FastGithubTray")`，`ERROR_ALREADY_EXISTS` → 直接返回（静默退出，不弹窗）。
- 剪贴板：`OpenClipboard/EmptyClipboard/SetClipboardData(CF_UNICODETEXT)/CloseClipboard`，内存用 `GlobalAlloc(GMEM_MOVEABLE)`。
- 提权安装证书：`ShellExecuteW(hwnd,"runas",exe,"install-cert",nil,SW_HIDE)`；用户取消 UAC（错误码 ≤32）视为无操作，不报错。

## 4. CLI 集成

- `run([]string{})` → 与 `tray` 同路径；`-h/--help/help` 仍打印用法。
- `tray` 子命令：加载配置（`--path`）、创建 store、`app.Run` 放到 goroutine，`ready(proxy, ui)` 回调里记录地址并启动托盘 `Run`；托盘 Quit → cancel context → 等 `app.Run` 返回。
- 管理员判定：`windows.GetCurrentProcessToken` 或 `OpenProcessToken` + `TokenElevation`；非 Windows 视为 false。
- 托盘启动失败（如无桌面会话）→ 回退为控制台 `run` 行为并打印原因。
