# MITM 双栈 HTTP/2 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让被 MITM 的域名在浏览器 ↔ 代理 ↔ 上游两段都使用 HTTP/2，并提供 `[server] http2` 开关回退旧行为。

**Architecture:** 下游由 `http.Server.ServeTLS` 在单连接 listener 上完成握手并注册标准库 h2 处理器（已 spike 验证）；上游由 `dialer.DialTLSH2` 通告 ALPN、`http.Transport` 打开 `ForceAttemptHTTP2`。带 `Upgrade` 的请求走独立 h1 transport 并做 101 透传。

**Tech Stack:** Go 1.22+（构建用 1.26.5）、仅标准库、零第三方依赖。

## Global Constraints

- 零第三方依赖：`go.mod` 只能有 `module` 与 `go` 两行，不得出现 `require`。
- 所有测试命令必须在 `$env:GOCACHE="D:\WorkSpace\CodeSpace\FastGithub\.gocache"; $env:GOPROXY="off"` 下执行。
- 每步提交前 `go vet ./...` 与 `gofmt -l .` 必须干净。
- 不得回归 v0.3.6 的 h1.1 行为：`http2 = false` 时代码路径必须与今天一致。
- 不引入 `golang.org/x/net/http2`。

```go
type transportOptions struct{ http2 bool }

// TransportOption 调整出站 transport 的协议栈。
type TransportOption func(*transportOptions)

// WithHTTP2 决定回源是否协商 HTTP/2。
func WithHTTP2(enabled bool) TransportOption {
	return func(o *transportOptions) { o.http2 = enabled }
}

func NewTransport(store *config.Store, d *Dialer, opts ...TransportOption) *http.Transport {
	var o transportOptions
	for _, opt := range opts {
		opt(&o)
	}
	target := func(addr string) (Target, error) { /* 保持不变 */ }
	dialTLS := func(ctx context.Context, network, addr string) (net.Conn, error) {
		t, err := target(addr)
		if err != nil {
			return nil, err
		}
		if o.http2 {
			return d.DialTLSH2(ctx, t)
		}
		return d.DialTLS(ctx, t)
	}
	tr := &http.Transport{
		DialContext:         func(ctx context.Context, network, addr string) (net.Conn, error) { /* 保持不变 */ },
		DialTLSContext:      dialTLS,
		MaxIdleConns:        64,
		MaxIdleConnsPerHost: 8,
		IdleConnTimeout:     90 * time.Second,
	}
	if o.http2 {
		tr.ForceAttemptHTTP2 = true
	} else {
		// 显式关闭：自定义 DialTLSContext 下这是唯一可靠的停用方式。
		tr.TLSNextProto = map[string]func(string, *tls.Conn) http.RoundTripper{}
	}
	return tr
}
```

**关键事实（已 spike 验证）：** 不能先自己 `Handshake` 再把 `*tls.Conn` 交给 `ServeTLS`——Go 1.26 的 `tls.Server` 不再复用已包装连接，会二次握手并报 `first record does not look like a TLS handshake`。正确做法是**把原始 `net.Conn` 直接交给 `ServeTLS`**，由它用 `GetCertificate` 选证书完成握手。

func (s *Server) serverTLSConfig(fallbackName string) *tls.Config {
	cfg := &tls.Config{
		GetCertificate: func(hello *tls.ClientHelloInfo) (*tls.Certificate, error) {
			name := hello.ServerName

```go
// serveOneHTTP 服务明文 HTTP 连接（80 入口）。
func (s *Server) serveOneHTTP(conn net.Conn, handler http.Handler) {
	s.serveConn(conn, nil, handler)
}

// serveOneTLS 把原始连接交给 ServeTLS：由它完成握手（GetCertificate 选叶证书）
// 并注册标准库 h2 处理器，这是启用 h2 的唯一标准库路径。
func (s *Server) serveOneTLS(conn net.Conn, cfg *tls.Config, handler http.Handler) {
	s.serveConn(conn, cfg, handler)
}

func (s *Server) serveConn(conn net.Conn, tlsCfg *tls.Config, handler http.Handler) {
	done := make(chan struct{})
	var once sync.Once
	srv := &http.Server{
		Handler:           handler,
		TLSConfig:         tlsCfg,
		ReadHeaderTimeout: 10 * time.Second,
		IdleTimeout:       5 * time.Minute,
		ErrorLog:          log.New(io.Discard, "", 0),
		ConnState: func(_ net.Conn, state http.ConnState) {
			if state == http.StateClosed || state == http.StateHijacked {
				once.Do(func() { close(done) })
			}
		},
	}
	l := &singleConnListener{conn: conn}
	go func() {
		if tlsCfg != nil {
			_ = srv.ServeTLS(l, "", "")
			return
		}
		_ = srv.Serve(l)
	}()
	<-done
}
```

注意：`serveConn` 里 `<-done` 依赖 `ConnState` 收到 `StateClosed`；`ServeTLS` 握手失败时也会触发关闭回调，不会泄漏。

`serveUpgrade`：

```go
func (p *ReverseProxy) serveUpgrade(w http.ResponseWriter, resp *http.Response) {
	back, ok := resp.Body.(io.ReadWriteCloser)
	if !ok {
		http.Error(w, "上游未返回可升级连接", http.StatusBadGateway)
		return
	}
	defer back.Close()
	hj, ok := w.(http.Hijacker)
	if !ok {
		http.Error(w, "当前服务器不支持连接劫持", http.StatusInternalServerError)
		return
	}
	client, brw, err := hj.Hijack()
	if err != nil {
		return
	}
	defer client.Close()
	resp.Header.Del("Transfer-Encoding")
	resp.Header.Del("Content-Length")
	if err := resp.Write(client); err != nil {
		return
	}
	done := make(chan struct{}, 2)
	go func() { _, _ = io.Copy(back, brw); done <- struct{}{} }()
	go func() { _, _ = io.Copy(client, back); done <- struct{}{} }()
	<-done
}
```
