## 2. 项目是什么

FastGithub 的 **Go 重写**：本地 DNS 净化 + IP 竞速 + TLS 中间人（本地 CA），解决 github.com 打不开/clone 失败。**不是翻墙**。
完整设计与可行性分析：`docs/specs/2026-10-20-fastgithub-go-design.md`。
实施计划：`docs/plans/2026-10-20-m1-config-foundation.md`（10 个任务，前 8 个已完成评审）。

### 5.1 `internal/config/toml.go` 接受畸形表头（Important）

- **症状**：`[a]]`、`[domains."github.com"]]` 被解析成垃圾键，稍后表现为困惑的 `未知配置项` 而不是解析错误。
- **修法**：`parseKeyPath` 的裸键分支（约 `toml.go:158-201`）对每个裸段做字符集校验，只允许 `[A-Za-z0-9_-]`；`]`/`[`/`!` 等一律报 `键名包含非法字符 %q`。带引号的键不受影响（随包配置用的就是引号通配键）。
- **测试**：`TestParseRejectsBadHeaderChars`，输入 `[a]]\n`、`[domains."github.com"]]\n` 必须报错。用变异验证：去掉字符集校验后该测试必须失败。
- **注意**：裸段含 `.` 的写法 `[a.b]` 是合法 TOML（点号拆段），字符集校验只在"段内"生效，不影响拆段逻辑。

### 5.2 `internal/config/store.go` 缓存无上限（Important）

- **症状**：`Store.cache` 对每个查询过的主机（含未命中）永久缓存（`store.go:14,48,58`）；M1-D/E 是常驻代理、按连接查询，可能被泛洪。
- **修法**（保持"命中+未命中"契约不变，因为 brief 与测试 `TestStoreCacheKeepsMisses` 要求 nil 未命中缓存）：插入前检查 `len(s.cache) >= 4096` 则整体重置 map。加 const `maxCacheEntries = 4096` 与注释说明"热重载/缓存重置后的语义"。补充测试：插入 4100 个唯一未命中后 `len(st.cache) < 4100`。
- 热重载（重建 Store）天然重置缓存，符合设计 §6.1。

## 9. M1-C 完成状态（2026-10-20）

- 计划：`docs/plans/2026-10-20-m1c-resolver.md`；实现：`internal/resolver/`（`dnsmsg.go`、`doh.go`、`resolve.go`、`cache.go`、`singleflight.go`、`race.go`）。
- 对外 API：`resolver.New(config.DNS)`、`(*Resolver).Lookup(ctx, domain) ([]net.IP, error)`。
- 查询链：DoH（`dns.doh` 顺序，`application/dns-message` POST，失败端点冷却 30s）→ 明文 DNS（`dns.fallback` 顺序，仅 TCP）。响应校验 ID/QR/TC/问题名/RCODE；NXDOMAIN 立即返回，SERVFAIL/NODATA 继续下一个源。
- 超时：`dns.timeout` 是整次解析的总预算（A/AAAA 并发共享），单个源在其内尝试。
- 缓存：正缓存 TTL 夹逼 30s~10min（CNAME 链取整链最小 TTL）；负缓存非 socket 错误 30s、`*net.OpError` 10min；缓存上限 4096，满时整体重置。A/AAAA 并发查询后合并去重。
- 竞速：未缓存 IP 并发 TCP 拨号 443（2s 上限，最多 32 个候选），按时延排序；IP→时延缓存成功 5min、失败 1min；全部失败保持原序。
- 并发：同域名查询经 singleflight 合并；共享查询与首个调用方的取消解耦，每个调用方仍按自己的 ctx 提前返回，调用方取消不会写入负缓存。
- 验证：`go test ./...`、`go test -race ./internal/resolver`、`go vet`、`gofmt` 全绿；六目标交叉编译成功。
- 下一里程碑：M1-D 拨号器与代理（38457、隧道、反向代理、PAC）。开工前须确认 `@ipaddress` 作 SNI 的语义（设计文档 §13），并决定 `Domain.Timeout` 零值语义与 destination 尾斜杠规范化。
