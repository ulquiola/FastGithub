## 2. 项目是什么

FastGithub 的 Go 重写：本地 DNS 净化 + 多 IP 竞速 + 本地 CA 中间人，解决 `github.com` 打不开 / clone 失败。**不是翻墙工具**。

两种工作方式：

- **显式代理**（全平台）：`127.0.0.1:38457`，CONNECT 命中域名规则时 MITM，未命中盲隧道；根路径返回 PAC。
- **透明拦截**（仅 Windows，WinDivert）：劫持 UDP 53 与 TCP 443/80/22/9418，浏览器无需配置代理。

域名规则只决定“哪些域名被接管/优化”，不决定“是否走代理”。当前 55 条规则来自原版 9 份 `appsettings.*.json`，在 `conf.d/`。

## 6. 已知问题与技术债（按优先级）

### P1：DNS 源只取第一个成功结果

`internal/resolver/resolve.go` 的 `lookupType` 在第一个成功源后立即返回，候选 IP 可能只有一个。macOS 实测 `github.com` 被解析到 `20.205.243.166` 时会间歇性 TCP 超时，而 `140.82.112.3` 等地址可用。

建议：把各源（DoH + fallback）的 A/AAAA 结果**合并去重**后再竞速；或在 `dialFirst` 全部失败时强制重新解析（绕过正缓存）。改动要有单测，避免把慢源拖进总预算。

### P2：`/api/intercept` 仍是 501

运行时启停透明拦截未实现。当前只能改 `intercept.mode` 后重启。实现时需要处理 WinDivert 句柄的并发启停与端口占用。

### ~~P2：`server.singleton` 解析但未生效~~（v0.5 已解决）

`internal/instance` 已实现：Unix 用 `flock` 锁 `fastgithub.lock`，Windows 用命名互斥量；`run` 与 `tray` 都会在绑定端口前获取，服务与手工启动共用同一把锁。

### P3：`log.level` 解析但未使用

目前没有分级日志，所有 `log.Printf` 都会输出。

### P3：系统代理只支持 macOS

`internal/sysproxy` 在 Windows/Linux 返回 `ErrUnsupported`，UI 显示“不可用”。Windows 有透明拦截，不需要系统代理；如果以后要支持，需写 WinINET 注册表 + `InternetSetOption` 刷新。

### P3：macOS 系统代理在异常退出时不会恢复

只有收到 SIGINT/SIGTERM 才会自动关闭；崩溃或 `kill -9` 会留下指向 `127.0.0.1:38457` 的代理。Windows 不涉及。

### P3：CI 与基准

- `.github/workflows/ci.yml` 在 Gitee 不生效；Gitee 侧需要自建流水线或本地跑 `scripts/ci.sh`。
- 基准已补（`make bench`、`docs/benchmarks-2026-10-21.md`）；后续可按结果优化 h2 的每流分配。

### v0.4.1（同日，h2 开关修复）

- **问题**：`[server] http2 = false` 时下游仍然协商 h2。`http.Server.ServeTLS` 在 `TLSNextProto` 为 nil 时会自动追加 `h2` 并注册处理器，仅从 `NextProtos` 里去掉 h2 不够。
- **修复**：`serveConn` 在 TLS 且 `http2=false` 时显式设置 `srv.TLSNextProto` 为非 nil 空 map。上游侧原本就通过空 `TLSNextProto` 关闭，无需改动。
- **测试**：`TestServeOneTLSFallsBackToHTTP1` 改为客户端主动 `ForceAttemptHTTP2: true`，断言服务端仍回退 h1——旧测试因为客户端没通告 h2 而漏掉了这个问题。
- **真机验证**：`curl --http2` 经代理访问 GitHub，`http2=true` 返回 `HTTP/2 200`，`http2=false` 返回 `HTTP/1.1 200`。

## 待办与新发现

1. **旧 CA 残留**：本机 `LocalMachine\Root` 与 `CurrentUser\Root` 各有一张 2022-06-19 签发、2032-06-20 到期的 `CN=FastGithub`（指纹 `0A1008…`），与本项目 CA（`8CC7A4…`，2026–2036）不同。管理员验收前应删除旧证书，否则浏览器仍信任旧 CA。
2. **服务 `uninstall` 非幂等**：服务不存在时报英文 `OpenService: The specified service does not exist` 并退出 1；建议视为成功。
3. **`release.sh` 依赖 `zip`**：Windows 默认无该命令，可在脚本里回退到 PowerShell `Compress-Archive`，或在文档标注前置条件。
4. 443 端口被其它进程占用（pid 随环境变化），验收“端口顺延”时可直接利用。
